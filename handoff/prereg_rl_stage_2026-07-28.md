## 1. ПЕРВАЯ СВОБОДА (что агент решает сам)

`FreedomConfig(exit_own=True, entry_own=False, params_own=False)`.
`WorldConfig.cb_equity_mode = "v7_ledger"` (леса копирования, transition заморожен).

- Агент может выйти РАНЬШЕ v7 — и ТОЛЬКО это. Honored только на **dip-in-position**
  барах (v7hook: агентский close на dip-сделке). На всех прочих барах
  (flat / transition-in-position / cooldown / после SL) вход и выход исполняет
  эксперт v7.
- SL, circuit-breaker, transition, post-exit cooldown у агента НЕ отбираются
  (жёсткие правила мира, `WorldConfig` без изменений).
- Головы SL/TP (nvec=1) вырождены и всегда замаскированы (`params_own=False`).

СЛЕДСТВИЕ ДЛЯ ЛОССА (реализовано в `algo/head_masking.first_freedom_head_mask`):
policy-градиент и entropy-бонус головы 0 считаются ТОЛЬКО по dip-in-position
барам. По манифесту это <1% всех баров (dip-сделок ~сотни, баров ~2.9M) — без
маски градиент головы 0 шёл бы почти целиком с forced-баров и коррелировал бы с
решениями эксперта, а не головы. Предикат dip-in-position — чистая функция obs
(столбцы `a_in_position`, `a_pos_tag_dip`; де-стандартизация через scaler семени).

ИЗВЕСТНАЯ OVER-INCLUSION (не быстрый фикс, вынести в контроль §6): маска
включает и dip-бары, где позиция закрывается ПРИНУДИТЕЛЬНО (SL, CB force-close,
close_at_end) — там сэмпл головы 0 причинно ни на что не влияет, но получает
advantage от исхода. Из текущего obs это чисто не исключить (forced-close решается
по fill на t+1). Пост-хок: посчитать долю dip-баров с forced-close; если >~5% —
вынести их из парной статистики гейта 4.2.

TRAIN/SERVE PARITY (обязательно ДО реального прогона): `SpotFlipEnv.observe()`
отдаёт СЫРЫЕ obs, а клон обучен на СТАНДАРТИЗОВАННЫХ (`apply_scaler`). В каркасе
это закрыто ФИКСИРОВАННОЙ обёрткой скейлера семени
(`ppo_scaffold.make_seed_scaler_vecenv`, НЕ VecNormalize) — buffer в
стандартизованном пространстве, где и клон корректен, и деста маски точна. Перед
прогоном обязателен parity-gate (см. §6, п.8).

## 2. НАГРАДА

Поминутный лог-прирост эквити `r_t = log(eq_t / eq_{t-1})`, `gamma = 1.0`
(EnvConfig, обязателен; НЕ 0.99 — иначе кредит на холдах до 34 738 баров затухает
как e^-погоризонт). Комиссия `fee_side=0.001` внутри награды (двусторонняя в
reward-эквити). Каркас PPO строится с `gamma=1.0` ЯВНО (сохранённое BC-семя имеет
дефолтный 0.99 — переопределяется; `build_scaffold` отвергает gamma≠1.0).

## 3. KL-ЯКОРЬ к клону

Штраф `+ β · KL(clone_head0 ‖ current_head0)`, усреднённый по ВСЕМ барам (flat и
transition держат политику у клона там, где агент не свободен; на dip-выходах KL
штрафует уход, а PPO его толкает). Клон — замороженный deepcopy семени.

**β [Ч?] — ПРАВИЛО (не число, не подбор по валидации) [требует утверждения]:**
на ОДНОМ фиксированном стартовом rollout (seed=0, до первого апдейта) подобрать β
так, чтобы `β · ‖∇_θ KL‖ ≈ 0.1 · ‖∇_θ PG‖` (KL-якорь на порядок слабее сигнала,
но не пренебрежим). Замер один раз, полученное β впечатывается сюда как
фиксированная константа и далее не трогается. Ориентир масштаба: **β ≈ 0.05..0.2**.

## 4. ЭНТРОПИЯ (разведка на dip-выходах)

Клон почти детерминирован: `entropy_flip_mean ≈ 0.0023` нат, `entropy_stay_mean
≈ 0.0017` нат (манифест reg_cd) → без принудительной энтропии FLIP на dip
практически не сэмплируется, PPO не увидит ни одного альтернативного выхода.
Базовая частота FLIP-выходов эксперта мала (exit-recall ~0.39 на 2021, но
абсолютно: must-copy-выходов 70/52 на эпоху; на dip-барах p(FLIP) порядка 1e-3).

**ent_coef [Ч?] — ПРАВИЛО [требует утверждения]:** подобрать так, чтобы на первом
rollout эмпирическая **p(FLIP) на dip-in-position барах попала в коридор
[1% .. 5%]** (достаточно, чтобы за бюджет шагов сэмплировать альтернативные
выходы по каждой dip-сделке; не настолько, чтобы разрушить копирование).
Ориентир масштаба: **ent_coef ≈ 0.005..0.02**. Логировать p(FLIP)@dip каждый
rollout — это диагностика разведки, а не средняя награда.

## 6. КОНТРОЛИ (3.3) — каждый с явным pass/fail

1. **Пермутация наград:** обучить на перемешанных по времени наградах; гейт
   ДОЛЖЕН провалиться (эффект → NULL). Если проходит — сигнал фиктивен.
2. **Мультисид:** 5 сидов; парный эффект и его знак согласованы (медиана > 0 у
   ≥4/5; ни один сид не даёт значимого отрицательного).
3. **Нижний бенчмарк «выход в случайный момент»** (random-within-dip-mask): RL
   обязан бить его парно по dip-сделкам.
4. **Верхняя планка — oracle-резерв** из Э0.2 (`analysis/oracle_reserve.py`):
   эффект RL должен лежать МЕЖДУ random-exit и oracle (иначе — утечка/баг).
5. **leave-top-k-out:** гейт выживает без top-2 dip-сделок по вкладу (эффект не
   держится на 2 сделках).
6. **Канарейка утечки:** обучить с занулённой/зашумлённой ключевой obs-компонентой
   агент-стейта; резкое падение эффекта ожидаемо, аномальный РОСТ — сигнал утечки.
7. **Анти-мемоизация:** temporal holdout (см. §5), джиттер стартов эпизодов,
   trade-dropout, ограничение ёмкости критика/политики. Эффект переживает.
8. **PARITY-GATE (пред-прогонный, обязателен):** прогнать reg_cd_vw2 через
   путь среды (`env.observe()` → обёртка скейлера семени) и сверить must-copy
   argmax-recall головы 0 против `handoff/honest_gate_reg_cd.json` (=1.0000).
   Если клон НЕ воспроизводит свой гейт на rollout-obs — стандартизация в петле
   сломана, прогон запрещён. Плюс assert: `apply_scaler(env.observe())` ==
   obs, попадающие в policy.
9. **Нормировка advantage:** сейчас по полному минибатчу, а в PG идут <1%
   dip-баров → dip-advantage масштабируется статистикой forced-баров. Проверить
   на первом rollout; при необходимости нормировать по dip-подмножеству.

## 7. ГЕЙТ УСПЕХА (4.2) [требует утверждения]

- **Минимальный практический эффект:** **+0.10 .. 0.15 % на dip-сделку**, ПАРНО
  (per-trade дельта RL−v7 на одной и той же сделке), считается по **dip-сделкам**
  (tail-guard: сделки, где вход = dip; transition/SL-исходы вне гейта).
- **Стат-критерий:** односторонний Wilcoxon signed-rank p < 0.01 И нижняя граница
  95% block-bootstrap CI медианной парной дельты > 0.
- **MaxDD:** не хуже согласованного предела **[Ч?]** — ПРАВИЛО: «MaxDD RL ≤ MaxDD
  v7 (тот же разрез, полный движок) + допуск δ». δ **[требует утверждения]**,
  ориентир **δ = 0.5 п.п. абсолютной просадки**; абсолют MaxDD v7 подставить из
  движкового прогона (`analysis/engine_run.py`), не гадать.

## 8. ПОЛ ПОЛЕЗНОСТИ (3.2) — NULL ≠ ДЕПЛОЙ (ключевой абзац)

Вердикт **«эффекта нет / KL задушил»** (НЕ «не хуже → деплой»), если ЛЮБОЕ:
- 95% block-bootstrap CI медианной парной дельты по dip-сделкам ВКЛЮЧАЕТ 0; ИЛИ
- медианный |сдвиг argmax головы 0 относительно клона| на dip-барах < ε
  (ε **[требует утверждения]**, ориентир **1%** dip-баров со сменой решения); ИЛИ
- p(FLIP)@dip на train так и не вышла из коридора §4 (разведки не было).

То есть «политика не отличается от клона» и «политика не хуже клона» — РАЗНЫЕ
вердикты; первый закрывает деплой, а не открывает его.
