## ШАГ 2 — обучение клона (BC, supervised)

Сеть = реальная политика sb3-PPO (`MlpPolicy`, копи-спек `MultiDiscrete([2,1,1])`,
net_arch pi/vf=(256,256)), обучается голова 0 (STAY/FLIP) по наблюдению v2.
Головы SL/TP вырождены (nvec=1 → log_prob≡0) и loss-маскированы (no-op). Сохранён
`model.save` → пригоден для засева PPO на этапе RL. Обучение детерминир. по сиду 0.

### Ключевой методический вывод (важно для RL-этапа)
Гейт требует, чтобы СКАЛЯРНЫЙ сдвиг логита дал ОДНОВРЕМЕННО FPR≤3e-7 и
recall≥99.5% → нужен зазор `min_FLIP(d) − max_STAY(d) ≥ logit(0.995)−logit(3e-7) ≈
20.3 nat`, где d=logit_FLIP−logit_STAY. Это L∞/max-margin задача (определяется
ХУДШИМ баром), НЕ средняя:
- **взвешенный BCE (w_pos=4000)** → зазор **−7.5 nat** (хвосты пересекаются),
  argmax при этом ИДЕАЛЕН (все сделки бар-в-бар при пороге 0);
- **средний маржинальный softplus-лосс** → ещё хуже (−10 nat): среднее не давит
  хвостовые выбросы;
- данные ОТДЕЛИМЫ (min L2-дистанция STAY→FLIP-выход = 0.947 в стандартиз.
  пространстве, 0 баров ближе 0.5) → неотделимость НЕ причина, причина — объектив.

**Решение (зафиксировано в модуле ДО замера гейта):** worst-case лосс через
logsumexp (гладкий max) + глобальный hard-negative mining STAY:
`L = logsumexp_FLIP(M−d) + logsumexp_{STAY∪HN}(M+d)`, M=12, HN=16384 глобально
худших STAY на шаг (пересчёт каждую эпоху). Достигнутый зазор — **87 nat** (обе
эпохи), s* = −83.17 в интервале [−125.5, −40.8].

**НО (см. критическую проверку ниже): 87 nat при цели 20.3 — подпись МЕМОИЗАЦИИ,
а не выученного правила. Объектив напрямую максимизирует метрику гейта на тех же
данных → in-sample зазор не несёт информации об обобщении.**

### ЧЕСТНАЯ ОГОВОРКА (не продаётся как обобщение)
Эпохи смешаны для BC (§6 pre-reg), истинного holdout НЕТ — этот гейт есть
воспроизведение v7 на ТОЙ ЖЕ ленте (что и есть бар-в-бар гейт). Зазор 87 nat при
808 положительных с hard-negative mining — это в значительной мере МЕМОИЗАЦИЯ
in-sample. Для BC-гейта это допустимо (цель — точное воспроизведение
детерминированной v7), но НЕ демонстрирует обобщение и без value-warmup/KL-якоря и
рыночного builder'а (часть 2 плана) НЕ переживёт RL/serve. Пороги SL/TP в BC
вырождены (n=1), не гейтятся.

### Главный сэмплированный гейт (100 сидов, per-epoch раздельно)
| Эпоха | зазор d | FPR mean/max | recall вход mean/min | recall выход mean/min | вердикт |
|-------|--------:|-------------:|---------------------:|----------------------:|:-------:|
| 2024  | 87.11   | 0 / 0        | 1.00000 / 1.00000    | 1.00000 / 1.00000     | ПРОШЁЛ  |
| 2021  | 87.99   | 0 / 0        | 1.00000 / 1.00000    | 1.00000 / 1.00000     | ПРОШЁЛ  |

FPR = 0 ложных FLIP за 100 сидов × ~2.9М STAY-баров (при s*=−83 худший STAY имеет
d+s*≈−52 → p≈1e-23). recall вход и выход = 1.0 раздельно, обе эпохи. Анти-
вырожденный `recall_flip>0` выполнен. FPR ≤ 3e-7 И recall ≥ 99.5% — ОБЕ стороны.

**ВНИМАНИЕ: этот in-sample результат ТАВТОЛОГИЧЕН** (объектив обучения = метрика
гейта на тех же барах). Он НЕ является доказательством готовности — см. критическую
кросс-эпоховую проверку ниже, которая его опровергает.

### Диагностика closed-loop (справка, НЕ go/no-go)
| Эпоха | доля чистых прогонов | \|Δкомпаунд\| residual min/med/max |
|-------|--------------------:|-----------------------------------:|
| 2024  | 100/100 = 1.000     | 0.000304 (валидир. эксперт, pre-reg §3) |
| 2021  | 100/100 = 1.000     | 0.000272 (валидир. эксперт, pre-reg §3) |

Чистый прогон = ноль отклонений от экспертного действия по всем барам → траектория
= экспертной → компаунд = экспертный под средой (residual уже валидирован в
pre-reg §3, « 1e-3). 0 грязных прогонов из 100. **NB: эти числа — тоже in-sample,
и раз главный зазор мемоизирован (ниже), они наследуют ту же тавтологию.**

## КРИТИЧЕСКАЯ ПРОВЕРКА — кросс-эпоховое ОБОБЩЕНИЕ (`spotrl/bc/generalization.py`)

Главный гейт in-sample ТАВТОЛОГИЧЕН: обучающий объектив (worst-case logsumexp-
маржа) напрямую максимизирует ровно `min_FLIP(d) − max_STAY(d)` — ту самую
величину, что проверяет гейт, на ТЕХ ЖЕ 2.9М барах. Три признака мемоизации:
зазор 87 nat при нужных 20.3 (×4), FPR≈1e-23 (вырожденные логиты), M=12 задан, а
вышло 87 (logsumexp не насыщает градиент, weight_decay≈0 → логиты растут
неограниченно). Правило v7 идентично в обеих эпохах → выученное ПРАВИЛО обязано
дать зазор и вне своей эпохи. Проверка (обучить на одной эпохе, замерить на другой):

| Обучение | IN-epoch зазор | OUT-of-epoch зазор | min_FLIP out | max_STAY out |
|----------|---------------:|-------------------:|-------------:|-------------:|
| 2021     | +50.4          | **−109.8**         | −14.3        | 95.5         |
| 2024     | +42.9          | **−157.6**         | −67.1        | 90.5         |

Out-of-epoch зазор КАТАСТРОФИЧЕСКИ отрицателен: min_FLIP уходит в минус (клон
ПРОПУСКАЕТ реальные FLIP вне своей эпохи), max_STAY взрывается до ~90 (массовые
ложные FLIP). **87 nat — подпись мемоизации по ШУМОВЫМ признакам (ценовые/объёмные
оси), а не выученного правила.**

Конструктивная проверка — обучение ТОЛЬКО на семантических признаках v7
(m_entry_signal, m_trans_entry_signal, m_exit_flag, m_leg_dn, m_sell/buy_margin,
m_bounce_pct, m_leg_age, a_unreal_pnl, pos_tag, a_cb_active, a_cooldown_remain,
a_entered_on_up):

| Обучение | IN-epoch зазор | OUT-of-epoch зазор |
|----------|---------------:|-------------------:|
| 2021     | **+0.5**       | **−8.4**           |
| 2024     | **−2.6**       | **−14.5**          |

Семантические признаки НЕ отделяют классы до 20 nat даже IN-sample (0.5 / −2.6).
Значит FLIP-решение v7 НЕ является чистой обобщающей функцией obs v2: жёсткие
STAY-бары (m_exit_flag=1 в даун-леге, где v7 НЕ выходит из-за b2b/leg-латча) не
отделимы по наблюдению от FLIP-выходов — согласуется с грубыми верхними границами
874/317k из ШАГ 1. In-sample argmax-успех (162/162 и т.д.) сам ехал на шумовых
признаках → тоже мемоизация. **Это MDP-недостаточность obs v2 для головы 0.**

## ВЕРДИКТ: КЛОН НЕ ГОТОВ (к RL-handoff)

Что СОЛИДНО и подтверждено:
- ШАГ 1: exit_collisions = k_tp = **0** (A=0 разрешён), метод честный.
- ШАГ 0: принятые пороги зафиксированы, прежние помечены SUPERSEDED.

Что ПРОВАЛЕНО (изменение вердикта относительно первого прогона):
- Главный сэмплированный гейт проходит in-sample **ТОЛЬКО ПО ПОСТРОЕНИЮ** (объектив
  обучения = метрика гейта на тех же данных). Кросс-эпоховая проверка: зазор
  −109.8 / −157.6 → разделение МЕМОИЗИРОВАНО.
- Даже на семантических признаках v7 зазор in-epoch 0.5/−2.6 → **obs v2
  недостаточно для воспроизведения FLIP-решения v7 как обобщающего правила**
  (MDP-недостаточность: exit-подавление b2b/leg-латч не наблюдаемо).
- Сохранённая политика имеет логиты ±80 (FPR≈1e-23) — это ОТРАВЛЕННАЯ
  инициализация для PPO (энтропия у нуля, гиперуверенность через шум). value-warmup
  и KL-якорь этого НЕ чинят.

### Направление фикса (для команды, ДО следующего захода)
1. **НЕ засевать PPO текущей политикой** `bc_clone_v7_policy.zip` — она
   мемоизирована и вырождена.
2. Первопричина — MDP-недостаточность obs v2 для головы 0 (не объектив, не ёмкость,
   не калибровка сдвига). Нужно расцепить: (а) обогатить obs состоянием
   exit-подавления v7 (leg-exit латч / b2b-память / непрерывные margin как ЧАСТЬ
   правила, а не шум) так, чтобы FLIP-решение стало чистой наблюдаемой функцией; или
   (б) признать, что сэмплированный гейт (FPR≤3e-7 И recall≥99.5% через скалярный
   сдвиг, ~20 nat) НЕДОСТИЖИМ обобщающим клоном на obs v2 и пересмотреть его
   (argmax-ёмкость + достижимый честный FPR, а разделение добирать на RL).
3. Регуляризация логитов (реальный weight_decay / клип нормы / cap на |d|) —
   обязательна в любом случае, чтобы политика годилась под PPO.
4. Кросс-эпоховая проверка (`generalization.py`) должна войти в гейт как go/no-go —
   без неё in-sample гейт кольцевой.

**Условия RL (value-warmup, KL-якорь, ent_coef, рыночный builder) вторичны, пока
не закрыта MDP-недостаточность головы 0.**
