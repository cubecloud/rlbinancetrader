# PRE-REG amend4 — терминальная per-trade награда + пониженный LR — 2026-07-29

Поправка к amend3. Основание: PoC (rl_first_freedom_poc) — 5/5 сидов
коллапсируют идентично; эквити пик на rollout 20 (1.075) → деградация до 0.627

## Принцип 1 — ТЕРМИНАЛЬНАЯ per-trade награда (финальная эквити как награда)

Значение имеет ФИНАЛЬНАЯ эквити сделки, не поминутный шум. Реализация:
`spotrl/envs/terminal_reward.RewardToTradeClose` (wrapper вокруг драйвера):
копит поминутный log-прирост эквити внутри позиции, отдаёт СУММУ одним скаляром
на баре ЗАКРЫТИЯ сделки, 0 на прочих барах в позиции.

- **Инвариант T7 сохранён:** Σ поминутного reward за сделку == терминальный
  скаляр == log(1+доходность). Проверяется численно (см. §Проверки).
- **Радиус мал (§1 k4_root_check):** CB читает КРИВУЮ эквити (`spot_env:375`
  просадка по world_equity), не скаляр награды → тайминг награды CB не трогает.
  Эквити-кривая обновляется mark-to-market каждый бар как раньше.
- **Немедленный кредит выходу:** агентский FLIP закрывает сделку → терминальный
  reward прилетает НА ТОМ ЖЕ баре решения о выходе. Дисперсия поминутного
  mark-to-market убрана с промежуточных dip-баров, дестабилизировавшая
  advantage на тонком dip-подмножестве (PoC-коллапс).

## Принцип 2 — ПОНИЖЕННЫЙ learning rate (против катастрофического забывания)

На тонком наборе (37 SL / 245 dip прокручиваются снова и снова) высокий LR
(дефолт SB3 3e-4) стирает выученное на одних сделках апдейтами на других →
политику мотает (p_flip 0.01%↔99%, dip-экспозиция схлопывается), плюсовое окно
rollout 20 не удерживается. LR пробуется НИЗКИМ (приоритет нижнему краю):
**{1e-4 (верхняя точка сравнения), 1e-5, 3e-6}** (при необходимости 5e-6).
Максимум 2-3 значения, без бесконечного подбора. Низкий LR учит медленнее →
горизонт достаточный (следить, что reward_equity ДВИЖЕТСЯ = сходимость, а не
отсутствие обучения).

## Гипотеза (что проверяем)
При терминальной награде + достаточно низком LR: удерживается ли ПЛЮСОВОЕ окно
(reward_equity >1.0, тип rollout 20) вместо пик-и-деградация в коллапс?
- УДЕРЖИВАЕТСЯ и портфель Σ выходит к нулю/плюсу на OOS → гипотеза подтверждена.
- Всё равно деградирует/коллапсирует → дело не в LR/тайминге, а в нехватке
  РАЗНЫХ сделок (вариативности) → честный вывод.

## Проверки ДО прогона
- T7 численно с терминальной наградой: терминальный скаляр на баре закрытия ==
  log(1+return_pct), 0 на прочих барах в позиции; |Δ| на паре сделок.
- Паритет драйвера с мин-холдом не сломан (recall must-copy=1.0, выход v7 не
  подавлен) — терминальная награда не меняет ДЕЙСТВИЯ, только reward.
