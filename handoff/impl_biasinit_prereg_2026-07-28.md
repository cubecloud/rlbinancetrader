## ЗАДАЧА 1 — BIAS-INIT КРИТИКА (замена недостижимого EV≥0.2)

Модуль `spotrl/bc/value_biasinit.py`. Последний слой критика
`policy.value_net = Linear(256, 1)`: **weight = 0, bias = mean(G) = 0.004414**
(mean return-to-go до конца сделки по всем барам, из кэша reward — без 20-мин
прогона среды). Выход критика становится КОНСТАНТОЙ = mean(G) на любом входе.

### Числа (реальный прогон CLI на reg_cd → reg_cd_vw2)

| Метрика | ДО | ПОСЛЕ |
|---|---|---|
| **SB3-EV, ВСЕ бары (in-sample)** — метрика порога | **−272.44** | **0.000000** |
| выход критика: max\|V − mean(G)\| | — | **0.00e+00** (константа) |
| value_net.weight абс. макс | — | **0.00e+00** |
| **логиты головы 0 бит-в-бит** (max\|Δd\|) | — | **True, 0.00e+00** |
| bias критика | 0.000000 | 0.004414 = mean(G) |

- EV_all из **−272 → ровно 0**: критик больше не «случайный гигант против таргета
  O(0.03)», а константа-среднее (EV константы-среднего = 1−Var(G−mean)/Var(G) = 0).
  Это чинит первый разрушительный PPO-апдейт из-за scale-mismatch. Порог EV≥0.2 не
  участвует — он недостижим на ~434 сделках (свойство данных, доказано в
  value-warmup), заменён на «масштаб выправлен + логиты бит-в-бит».
- **Логиты политики НЕ изменились** (max\|Δd\| = 0.0) — bias-init трогает только
  критика.
- weight=0 **НЕ замораживает** критика: градиент MSE `dL/dW = 2(V−G)·h`, h≠0 → на
  первом же PPO-апдейте веса уходят от нуля, критик доучивается on-policy
  (проверено тестом `test_bias_init_weight_not_frozen_by_zero`).
- Сохранено: `bc_clone_v7_policy_reg_cd_vw2.zip` + `.manifest.json` (со scaler
  reg_cd, obs_cols, блоком `value_biasinit`).

## ЗАДАЧА 2 — PRE-REG (полный документ: `handoff/prereg_rl_stage_2026-07-28.md`)

Предложенные пороги (все **[требует утверждения]**):

- **Первая свобода:** exit_own только, honored на dip-in-position; SL/CB/transition/
  cooldown у агента НЕ отбираются; cb_equity_mode=v7_ledger.
- **Награда:** поминутный log-прирост эквити, gamma=1.0 (явно в каркасе; отвергает
  0.99 — тихий убийца кредита на длинных холдах).
- **KL-якорь β:** ПРАВИЛО, не число — на одном стартовом rollout β·‖∇KL‖ ≈
  0.1·‖∇PG‖; ориентир β≈0.05..0.2. По ВСЕМ барам (клон держит forced-бары).
- **Энтропия ent_coef:** ПРАВИЛО — p(FLIP)@dip в коридоре [1%..5%] на первом
  rollout; ориентир 0.005..0.02. Мотив: клон детерминирован (entropy_flip≈0.0023
  нат), p(FLIP)@dip базово ~1e-3.
- **Геометрия:** train 2021-01..2024-03; тюнинг-фолды 2024-03..2026-01
  (anchor-inflated, только относительные); holdout 2026-01..2026-07 вскрыть ОДИН
  раз; на каждом разрезе — парная per-trade статистика (Wilcoxon+block bootstrap)
  И полный движок.
- **Контроли (7):** пермутация наград (обязан провалиться), 5 сидов, нижний бенч
  random-exit (обязан бить), верх oracle-резерв, leave-top-2-out, канарейка
  утечки, анти-мемоизация (temporal holdout/джиттер/dropout/ёмкость).
- **Гейт 4.2:** +0.10..0.15%/dip-сделку ПАРНО, Wilcoxon p<0.01 И нижняя граница
  95% block-bootstrap CI > 0; MaxDD ≤ MaxDD v7 + δ (δ≈0.5 п.п., абсолют v7 из
  движка `[Ч?]`).
- **Пол полезности (3.2):** NULL ≠ деплой — если CI дельты включает 0 ИЛИ медианный
  |сдвиг argmax vs клон| на dip < ε(≈1%) ИЛИ p(FLIP)@dip не вышла из коридора →
  вердикт «эффекта нет / KL задушил», НЕ «не хуже → деплой».
- **Бюджет/останов `[Ч?]`:** N_STEPS≈2..5 млн; ранний останов только по KL-cap
  (≈0.05 нат) или бюджету, НЕ по val-P&L.

Незакрытые `[Ч?]` (число до прогона): β, ent_coef, N_STEPS, KL_CAP, MaxDD-δ и
абсолют MaxDD v7 — все заданы как правило/ориентир, требуют утверждения
пользователем (П8).

## ЗАДАЧА 3 — КАРКАС PPO (только каркас; smoke прошёл, обучение НЕ запускал)

`spotrl/algo/ppo_scaffold.py`:
- `build_scaffold(env, seed, manifest, kl_coef, ent_coef, gamma=1.0, ...)`:
  строит sb3.PPO с gamma=1.0, грузит state_dict семени reg_cd_vw2, приморозит
  deepcopy-клон, подменяет `train()` на версию с loss-masking головы 0
  (dip-in-position, побарная маска на surrogate и entropy) и KL-якорем к клону по
  всем барам. Отвергает gamma≠1.0. Оборачивает env ФИКСИРОВАННЫМ скейлером семени.
- `make_seed_scaler_vecenv(...)`: VecEnv-обёртка `obs → apply_scaler(obs, mu, sd)`
  — train/serve parity (SpotFlipEnv отдаёт сырые obs, клон обучен на
  стандартизованных). НЕ VecNormalize (бегущий mu/sd сломал бы паритет).
- `smoke_scaffold(...)`: dummy-env (obs_dim=39, MultiDiscrete([2,1,1])), learn(100).

### SMOKE (реальный прогон на семени reg_cd_vw2)

```
{'started': True, 'gamma': 1.0, 'clone_frozen': True, 'n_steps': 100, ...}
```

Связка стартует и прогоняет 100 шагов без падения. gamma==1.0, клон-якорь
заморожен (ни один параметр не требует градиента).

ВАЖНО (ограничение smoke): dummy-env даёт неинформативный obs → маска dip
семантику НЕ проверяет (крэша нет, но и градиента головы 0 нет). Семантику маски
проверяет отдельный unit `test_head_mask_dip.py` на руками собранном батче

## ЗАМЕЧАНИЕ РЕВЬЮ (blocking, исправлено в этой итерации)

Исходный план использовал `head_loss_mask`, где голова 0 активна ВСЕГДА. Но
голова 0 обслуживает и вход, и выход, а при entry_own=False агент honored только
на dip-выходах (<1% баров). Без dip-маски >99% policy-градиента головы 0 шло бы с
forced-баров и коррелировало с решениями эксперта, а не головы — это топит сигнал
и ломает интерпретацию гейта 4.2. Исправлено: `first_freedom_head_mask` активирует
голову 0 ТОЛЬКО на dip-in-position (чистая функция obs), PG/entropy маскируются по
dip, KL-якорь — по всем барам.
