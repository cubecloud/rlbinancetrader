## 2. Э0.4 — каркас пакета `spotrl/`

### Почему такое имя

`spotrl` = spot + RL: пакет обучает RL-агентов ровно для спота Binance
(long/flat, без плеча и шортов). Имя не пересекается ни с `strategy_rl`
(старый слой моста, остаётся на месте), ни с `binanceenv`/`rllab`, и не
обещает большего, чем делает.

### Созданные файлы (все — новые)

```

spotrl/config.py                       WorldConfig (world_version, правила мира
                                       как ПАРАМЕТРЫ), FreedomConfig (флаги
                                       исполнения вместо масок), EnvConfig
                                       (gamma ровно 1.0, проверяется)
spotrl/spec/actions.py                 ActionSpec: MultiDiscrete([2, n_SL, n_TP]),
                                       STAY/FLIP, корзины SL/TP, expert_action()
spotrl/spec/observation.py             ObservationSpec + слоты rule_slot_0..2
```

Про отложенный замер честно:

- **Скорость 97.5k шаг/с против ориентира 754k.** Это каркасная реализация:
  на каждом шаге создаются объекты `AgentState`/`WorldState` и новый массив
  наблюдения (`np.empty` в `build_observation`). С таким устройством шага
  754k недостижимы в принципе — ориентир берётся записью в заранее
  выделенный буфер наблюдения вместо создания объектов. Оптимизация в
  задачу этого запуска (каркас) не входила; 97.5k — стартовая точка замера,
  а не достигнутый результат.

### Что сделано по существу, а не только «структура»

- **Награда тождественна цели.** Сумма поминутных лог-приростов эквити за
  сделку равна `log(1 + Return/100)` с точностью 1e-6 — проверяется Т7 на
  реальном прогоне среды. Учёт ведётся через количество (`_qty`), комиссия
  обеих сторон внутри награды. Второй тест Т7 требует, чтобы при γ=0.99
  тождество ЛОМАЛОСЬ — иначе тест мёртвый.
- **γ=1.0 не опция:** `EnvConfig.__post_init__` кидает ValueError на любом
  другом значении.
- **Наблюдение чистое:** пик незакрытой доходности двигает `TradeBook.mark`,
  а не вычисление наблюдения (дефект `policyio.py:57-59` не повторён);
  проверяется Т2 в позиции и вне позиции.
- **truncated, не terminated:** `step` всегда возвращает `terminated=False`,
  обрыв по длине — `truncated=True` (Т5), и ни одна сделка не остаётся без
  исхода (правило `close_at_end`).
- **Правила мира — параметры.** Добавление правила = предикат в
  `worldrules.check_forced_exit` + флаг в `WorldConfig` + запись в манифест.
  `world_version` в манифесте, `compare_world_version` запрещает сравнивать
  числа из разных миров.
- **Слоты `rule_slot_0..2`** в наблюдении константны (Т2), размерность входа
  при добавлении правила не поменяется.
