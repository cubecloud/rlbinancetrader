## §3-amend. Раздельный KL-якорь + адаптивная разведка

1. **KL-якорь РАЗДЕЛЬНЫЙ.** Полная сила (β=0.369) на FORCED/копирующих барах
   (~dip: flat, transition-in-position, cooldown, post-SL — там нужна ТОЧНОСТЬ
   копирования v7). На dip-in-position барах якорь = 0 (там свобода раннего
   выхода). Реализация: маска якоря = `~dip_mask` (зеркало loss-маски свободы).
   Это снимает корень удушения (якорь давил именно там, где нужна разведка).

2. **Адаптивный ent_coef.** Вместо фиксированного — контроллер удерживает
   p(FLIP)@dip в коридоре [1%,5%] (таргет 3%): после каждого rollout
   `log(ent_coef) += lr_ent·(log(target)−log(p_flip_dip_measured))`,
   ent_coef ∈ [1e-4, 0.5], lr_ent=0.3. Таргет — по НАБЛЮДАЕМОЙ доле FLIP на dip,
   а не по in-sample энтропии.

3. **Перекалибровка OOS.** β и старт ent_coef мерить на НЕСКОЛЬКИХ разнородных
   окнах train (2021-01..2024-03): обучил на окне A — замерил p(FLIP)@dip на окне
   B (out-of-sample). Регистрируется, какой старт даёт коридор OOS.

## §1-amend. Семантика dip-свободы: РАНЬШЕ, но не ПРОПУСТИТЬ (hard-stop A)

Уточнение к §1 «агент может выйти РАНЬШЕ v7 — и ТОЛЬКО это». На dip-in-position
баре исполнение: `FLIP если (агент FLIP) ИЛИ (v7-выход на этом баре), иначе STAY`.
То есть агент может закрыть РАНЬШЕ, но НЕ может ПРОПУСТИТЬ штатный выход v7 (v7-выход
жёстко срабатывает). Следствие: must-copy recall=1.0 гарантирован конструктивно;
набор входов v7 (272/162) сохранён; отличие от v7 — только в БОЛЕЕ РАННИХ выходах.
Драйвер: `FirstFreedomDriver(enforce_v7_exit=True)`.

## Контроли (регистрируются ДО просмотра прибыли) — §6-amend

Пороги/правила фиксированы ДО прогона, считаются на train + tune-fold (НЕ holdout):

- **K1. Бенчмарк «случайный выход» (нижний):** политика, которая на dip-in-position
  барах выходит FLIP со СЛУЧАЙНОЙ вероятностью, равной средней p(FLIP)@dip RL
  (matched exposure), иначе STAY; входы/форсы — те же (драйвер). RL ОБЯЗАН бить его
  ПАРНО по dip-сделкам (медианная per-trade дельта RL−random > 0, знак устойчив).
  Не бьёт — эффект неотличим от случайного тайминга, НЕ деплой.
- **K2. Пермутация наград:** обучить на перемешанных по времени наградах; парный
  эффект ОБЯЗАН провалиться (→NULL). Проходит — сигнал фиктивен, СТОП.
- **K3. leave-top-2-out:** убрать 2 dip-сделки с наибольшим вкладом в эффект;
  эффект (знак + значимость) ОБЯЗАН пережить. Не переживает — эффект на 2 сделках.
- **K4. Мультисид (5):** медианная парная дельта > 0 у ≥4/5 сидов; ни один сид не
  даёт ЗНАЧИМО отрицательного. Иначе — нестабильно, НЕ деплой.
- **K5. Пол полезности (§8 базового pre-reg действует):** если 95% block-bootstrap
  CI медианной парной dip-дельты включает 0 ИЛИ |сдвиг argmax vs клон| на dip < 1%
  ИЛИ p(FLIP)@dip не держалась в коридоре → вердикт «эффекта нет», НЕ деплой.

Гейт успеха 4.2 (базовый pre-reg §7) не меняется: +0.10..0.15%/dip-сделку парно,
Wilcoxon p<0.01 И нижняя граница 95% CI > 0; MaxDD ≤ v7 + δ.

## §4-amend. Гейт разведки: p(FLIP)@dip снят с авто-STOP (утв. пользователем)

Обоснование (эмпирика, ОБНОВЛЕНИЕ 4 в `rl_first_freedom_run_2026-07-28.md`):
ранний выход — ПОГЛОЩАЮЩЕЕ действие (FLIP закрывает позицию → dip-холд кончается).
Средняя per-bar p(FLIP)@dip доминируется массой уверенных STAY клона; реальные
ранние выходы редки (несколько на сделку) → средняя держится <1% даже когда выходы
происходят. Ослабление якоря → как только p(FLIP) растёт, dip-сделки закрываются
рано → dip-холд-бары исчезают → метрика рушится (n_dip→0). **Устойчивого 3% на
per-bar средней не существует — метрика плохо определена для поглощающего выхода.**
Проверено на 3 режимах (полный/адаптивный/фикс. слабый якорь).

Правки:
1. **p(FLIP)@dip — СНЯТ с авто-STOP**, остаётся лог-диагностикой каждый rollout.
2. **Настоящий критерий успеха = гейт 4.2** (парная per-trade dip-дельта RL−v7,
   Wilcoxon p<0.01 И нижняя граница block-bootstrap CI > 0, +0.10..0.15%/сделку;
   MaxDD ≤ v7 + δ). Оценка на train + tune-fold, БЕЗ holdout.
3. **Обязательный контроль (K1 усилен):** бенчмарк «случайный выход» — RL ОБЯЗАН
   бить его ПАРНО (тот же счётчик выходов, случайные моменты). Плюс пермутация
   наград (K2) и leave-top-2-out (K3).
4. **Авто-STOP теперь:** коллапс dip-экспозиции (n_dip→0 устойчиво) / KL_forced
   устойчиво > 0.05 / NaN / катастрофа наградной эквити. (p(FLIP)-STOP удалён.)
5. **Режим прогона:** фикс. слабый dip-якорь `bdip=0.05` (устойчивый, без
   коллапса), полный β=0.369 на forced-барах.

Не смотреть на голую эквити как на доказательство — только парная статистика с
контролем «случайный выход». RL не бьёт случайный выход ИЛИ CI включает 0 →
честный вердикт «эффекта нет», не подгонять.
