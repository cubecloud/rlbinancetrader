## 2. Дефолты кода (переключены в этом этапе)

`spotrl/algo/k4_run.py` — дефолтная сборка без env-переменных = стек выше:
- `FF_SEED_MODEL` → **vwk4cls** (был vw2 bias-init);
- `FF_TERMINAL` → **1** (была поминутная);
- `FF_PSL` → **1**, `FF_ALPHA` → **0.5** (был выкл / 1.0);
- `FF_LR` → **1e-5** (был 3e-4);
- `FF_EPLEN` → **262144** + джиттер стартов из flat-баров (был полный проход);
- `FF_WD`=1e-4, `FF_BDIP`=0.10, `FF_MINHOLD`=0.0245, ent=0.03 — без изменений.
Устаревшие пути (vw2, поминутная награда, без приора, полный проход в обучении)
доступны ТОЛЬКО явной env-переменной — история не удалена, дефолт переключён.
`_make_env(..., episode_len=)` — новый опциональный параметр (None = полный
проход, прежнее поведение).

## 4. Границы базы (что стек НЕ решает — из аудита)

Стек стабилен и селективен, но на одном символе (37 train / 8 OOS SL-сделок)
deploy-планка (SL взято И Σ≥0 OOS) не взята — упор в число независимых
эпизодов (аудит §1.4: нужно ~450–1200 dip / 70–180 SL). Джиттер лечит
мемоизацию/детерминизм обучения, но НЕ добавляет статистической мощности
вердикта. Следующие решения — Этап 1 аудита (данные), не алгоритмы.
